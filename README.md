# Drakengard 3 (PS3) Türkçe Yama
*NieR'in köklerinin köklerini anlatan* Drakengard 3 (Japon pazarında Drag-On Dragoon 3) için "Türkçe Dil Desteği" yaması üzerinde bir süredir çalışmaktayım.
Amacım benim gibi NieR serisinin sevmiş, benimsemiş, tutkusu haline getirmiş Türk hayranlarının bu oyunu dil engeli olmaksızın tadını çıkarabilmelerini sağlamaktır.

**Tüm ana oyun ve hikaye DLC'leri çevrilmiştir.**
